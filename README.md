# 📝 Quantom Byte - Ticketing System  

**Quantom Byte** is a **fullstack ticketing system** designed to streamline **interdepartmental communication** and **task management**. Built with modern technologies, it provides a **seamless** and **efficient** way for teams to **track, manage, and resolve tickets** in an organized manner.  

---

## 🚀 Features  
 
✅ **🔐 Secure authentication** –  with **Clerk**.  
✅ **🎨 Modern UI/UX** – Built with **Shadcn UI** and **Tailwind CSS** for a sleek, responsive interface.  
✅ **🗄️ Scalable Backend** – Powered by **Supabase** and **Drizzle ORM** and **Next.js api** for efficient database management.  
✅ **🧩 Modular Architecture** – Well-structured routes and API endpoints for easy maintenance.  
✅ **🌙 Dark & Light Mode** – Enhanced user experience across different environments.  
✅ **📱 Fully Responsive Design** – Optimized to look great on all devices.
